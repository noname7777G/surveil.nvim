# `surveil.nvim`

Offline search for Magic, the Gathering(TM) cards.
Uses card data provided by Scryfall's bulk data API.
Currently supports the following Scryfall syntax:
- simple card name search
- o/oracle
- t/type
- c/color
- id/identity
- mv/manavalue
- game
- f/format
- pow/power
- tou/toughness
- loy/loyalty
- defense
- set
